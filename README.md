# MedNexa (MediFlow AI)

> Native-style healthcare platform for rural Primary Health Centres (PHCs) to predict medicine stockout risks, track inventory, and rescue expiring batches via automated inter-PHC transfers.

---

## 🚀 Features

- **Real-Time Inventory Management**: Complete tracking of vital medicines, batch numbers, expiry dates, and unit stock.
- **AI Stockout & Expiry Risk Forecasting**: Algorithmic prediction of depletion risks, seasonal spikes (e.g., monsoon vector-borne surges), and impending expiries.
- **Inter-PHC Medicine Rescue Network**: Automated discovery of nearby PHCs with surplus inventory and transfer dispatch tracking (ETA, cold-chain status, dispatch notes).
- **Offline Ledger Syncing**: Designed for low-connectivity rural health centers with localized cache and warehouse ledger synchronization.
- **Multilingual Support**: English and Tamil language switching tailored for district health workers.
- **Android Native Experience**: Material Design 3 UI modeled for tablets and smartphones used by PHC medical officers and pharmacists.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Icons & Motion**: Lucide React, Motion
- **AI Engine**: @google/genai SDK
- **Bundler**: Vite 6+
- **Styling**: Tailwind CSS v4

## 💻 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/jananiii2972007-eng/mednexa.git
cd mednexa

# Install dependencies
npm install

# Start local development server
npm run dev
```
